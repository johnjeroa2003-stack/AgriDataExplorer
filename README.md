# AgriData Explorer: Understanding Indian Agriculture with EDA

## Domain
Agricultural Analytics

## Objective
To analyze Indian agricultural data at state and district level and build an interactive data visualization platform that provides insights into crop production, yield, and cultivated area.

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Plotly)
- SQL (MySQL)
- Power BI
- VS Code

## Dataset
ICRISAT District Level Agricultural Data
